Frequently Asked Questions

What Instagram links are supported?

Support depends on the connected media API. Public and authorized Instagram content should be used.

Can I download private Instagram posts?

No. This website is not intended to bypass private accounts, login requirements, DRM, or other access restrictions.

Can I download audio?

If the API returns an audio media file, InstaSave will show an audio player and an option to open the file.

Is an API key shown to visitors?

No. The RapidAPI key is stored on the server as an environment variable and is not placed inside this frontend code.

About InstaSave

InstaSave is a simple web tool designed to make supported Instagram media retrieval easier. Paste an eligible Instagram URL and the connected server checks whether downloadable media is available.


InstaSave does not provide access to private content or attempt to bypass authentication, DRM, or platform security.


Users are responsible for ensuring that they have the necessary rights or permission to download and use any media.
